# ICABR 2026 Budget Tool

An interactive R Shiny application designed to support transparent and flexible budget planning for the ICABR 2026 conference.

## Live application
The app is deployed and publicly accessible here:  
👉 https://diegomacall.shinyapps.io/icabr_budget_app/


## What it does
- Models conference income streams, including adjustable external contributions
- Captures fixed and variable costs by unit (e.g. coffee breaks, rooms, services)
- Provides scenario-based summaries with visual outputs
- Allows users to download budget scenarios as CSV files

## Technology
- R
- Shiny
- ggplot2
